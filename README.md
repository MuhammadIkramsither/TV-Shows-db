Research and Development (RND)
Introduction

Research and Development (RND) was conducted during this project to explore the use of database systems and business intelligence tools in real-world data analysis. The purpose of the research was to understand how data can be stored, processed, analyzed, and visualized effectively using modern technologies.

Research Areas

The following areas were researched during the development of this project:

Database Management Systems (DBMS)
SQL queries and database operations
EER diagram modeling
Data cleaning and transformation
Data visualization techniques
Dashboard development in Power BI
Interactive filtering and reporting
Development Process

The development process of the project was completed in multiple stages:

Collection of TV shows dataset
Data cleaning and organization
Creation of database and tables in MySQL
Insertion and management of records using SQL queries
Development of EER diagram to represent database structure
Importing dataset into Power BI
Creating charts, graphs, and slicers for visualization
Designing an interactive dashboard
Preparing final project documentation and report
Purpose of RND

The purpose of the research and development process was to gain practical knowledge of database systems and business intelligence tools. It also helped in improving skills related to SQL query writing, database design, dashboard development, and data visualization.
